# Security Policy — FrameCut Studio

**FrameCut Studio** (`com.itamadersomajinc.framecut`)  
**Engineered & Published by IT AMADERSOMAJ INC.**

FrameCut Studio processes untrusted media containers (MP4, MKV, MOV, TS), audio streams, project interchange files, fonts, and GPU shaders with strict memory safety in pure Rust.

## Reporting a Vulnerability

If you discover a security vulnerability within FrameCut Studio, please submit a report directly to:
- **Email:** `security@amadersomaj.com` or `contact@amadersomaj.com`
- **Private Advisory:** You may also use [GitHub Private Vulnerability Reporting](https://github.com/mohammad-sheikh-shahinur-rahman/FrameCut-Studio-Windows/security/advisories/new).

Please include:
1. FrameCut Studio version or commit hash.
2. Operating system and GPU hardware environment.
3. Proof-of-concept description or non-exploitable sample fixture.
4. Expected vs observed behavior.

We take security seriously and will investigate and coordinate a patch promptly. All contributions and reports are handled with confidentiality until a public advisory and patch release are made available.
